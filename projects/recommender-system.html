Case Study

Movie Recommender System

A hybrid MovieLens recommender — matrix-factorization collaborative filtering combined with genre-based content scoring — plus a semantic search feature that finds movies from natural-language descriptions using sentence-transformer embeddings.

Overview

The core recommender blends two signals: a matrix-factorization model that learns hidden preference patterns from the ratings matrix, and a content-based genre-similarity score that keeps recommendations explainable and solves the cold-start problem for brand-new movies. A separate semantic search endpoint lets a user type a description like "mind-bending sci-fi thriller" and get back ranked matches by embedding cosine similarity.

Semantic search

POST /api/search/description
{ "query": "mind-bending sci-fi thriller", "top_k": 5 }

→ [
  { "title": "Inception",  "year": 2010, "genres": ["Action","Sci-Fi","Thriller"], "similarity": 0.92 },
  { "title": "The Matrix", "year": 1999, "genres": ["Action","Sci-Fi"],             "similarity": 0.89 }
]

Collaborative filtering — matrix factorization with biases

Every predicted rating is a sum of four components:

Predicted Rating = Global Mean + User Bias + Movie Bias + Latent Factor Interaction

The model learns 15 latent dimensions per user and per movie — invisible traits like "how much this user loves action" or "how strong this movie's sci-fi elements are" — purely from the ratings matrix, with no genre labels involved.

Worked example — predicting Alice's rating for "Inception"

Global baseline 3.52 + Alice's user bias (+0.30, a generous rater) + Inception's movie bias (+0.50, a high-quality film) + latent factor match (+0.62, her love of action/complex-plots/sci-fi aligns with the film's profile) = 4.94 / 5.

Content-based filtering — Jaccard genre similarity (20% weight)

Similarity Score = Common Genres / Total Unique Genres

Inception vs. The Matrix share all three genres (Action, Sci-Fi, Thriller) → similarity 1.00. Inception vs. Titanic share none → similarity 0.00. A user's past ratings are then weighted by similarity to produce a content-based prediction — this is what lets the system recommend a brand-new movie that has never been rated by anyone.

Hybrid combination

Hybrid Score = (0.8 × Collaborative Score) + (0.2 × Content Score)

The 80/20 split was chosen empirically, not assumed. Sweeping the blend ratio during development showed pure collaborative filtering alone (RMSE 0.92) and pure content-based alone (RMSE 1.15) both underperform the 80/20 hybrid (RMSE 0.86) — a 50/50 blend was also tested and came out worse (RMSE 0.94) than either extreme-leaning option.

Training

90,274 ratings are split 60/20/20 into training, validation, and test sets. The model trains with stochastic gradient descent for up to 50 epochs, with early stopping after 10 epochs without validation improvement.

A test RMSE of 0.86 on a 0.5–5.0 star scale means predictions land within roughly 17% of the true rating on average. The near-identical validation and test RMSE (gap of just 0.0013) is the strongest signal here: it means the validation set was a reliable proxy for real generalization, and the model wasn't quietly overfitting to it.

Real recommendation quality

For a heavy user (842 ratings) who favors critically-acclaimed dark dramas like The Godfather and Fight Club, the top recommendations were Paths of Glory, Man Bites Dog, and Three Billboards Outside Ebbing, Missouri — all Crime/Drama, all thematically dark, none of them simply "popular movies." For a light user (28 ratings) who rates almost everything 5 stars on action blockbusters, the model still surfaced The Shawshank Redemption as a top pick, driven by the user-bias correction rather than genre overlap alone.
